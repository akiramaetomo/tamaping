# tamaping

[English README](README.md)

**粒子を弾く。音がほどける。心がゆるむ。**

tamaping は、ブラウザで動く小さな「粒子と音の遊び場」です。

パーティクルは漂い、ぶつかり、集まり、散り、光り、ときどき文字の形に
並びます。ステージをクリアするゲームではありません。スコアを競うアプリ
でもありません。動きに触れ、音を奏で、心地よい粒子の世界に身をゆだねる、
そんな小さなアプリです。

こちらで遊べます:

https://akiramaetomo.github.io/tamaping/

## 目的

tamaping の第一目的は、粒子を弾く心地よさ、音がほどけていく感覚、
そして画面に少し入り込むような没入感によって、心がゆるむ時間を作る
ことです。

材料はとても素朴です。パーティクル、ボール、衝突、重力、色、短い音。
けれど小さな反応がたくさん重なると、リズム、ノイズ、群れ、波、火花、
そして少し予想外の気持ちよさが生まれます。

物理を正確に説明することが目的ではありません。単純な仕組みに触れながら、
自分だけの「いい瞬間」を見つけるための場所です。

## パーティクル楽器のようなもの

tamaping は、スクリーントイ、効果音マシン、物理スケッチ、そして小さな
ビジュアル楽器の中間にあります。

大きなボールは、画面の中に入ったあなたの手です。パーティクルの雲を押す。
密集した粒の中へ打ち込む。画面の端へ弾き飛ばす。するとパーティクルは
動きと音で返事をします。

静かなプリセットが急に打楽器のようになったり、密度の高いプリセットが嵐の
ようになったり、単純な設定に生き物のような躍動感を感じられたりします。

正しい遊び方はありません。気になる雰囲気を選び、そっと乱してみる。
粒子と音が、思いがけない表情で応えてくれるはず。

## まず触る

1. アプリを開きます。
2. 画面を一度タップまたはクリックして、ブラウザの音を有効にします。
3. Settings からプリセットを選びます。
4. ボールをドラッグ、または軽く弾きます。
5. プリセットを変えて、同じ操作の手触りがどう変わるか試します。

気軽に眺めるときは Settings を `Small` にするのがおすすめです。画面を
隠しすぎず、プリセットを次々に試せます。

## プリセット

プリセット選択では、短い記号で種類を分けています。

- `F01`, `F02`, ... は組み込みのファクトリプリセットです。
- `U01`, `U02`, ... はユーザープリセット枠です。

ファクトリプリセットは読み取り専用の出発点です。動きと音の小さなギャラリー
として並んでいます。

- 光る粒子の雲
- 重力で集まる密集パーティクル
- ボールと粒で鳴らす打楽器的なシーン
- 蛇のように動く連結実験
- 文字や渦巻きから始まる演出
- ノイジーな効果音、静かに眺めるプリセット

一部のファクトリプリセットは、選んだ直後に特別な初期配置から始まります。

- `Flash`: 渦巻きのような配置から始まります。
- `Name`: パーティクルが文字の形から始まります。
- ランダム開始: 通常の散らばった配置から始まります。

この最初の一瞬も、プリセットの個性です。Settings が画面を隠しすぎるときは
`Small` にするか、閉じて眺めてください。

## 操作

### ボール

大きなボールが主な操作対象です。

- PCではマウスやポインタで動かします。
- スマートフォンでは指で触ってドラッグします。
- すばやく弾くと、衝突が鋭くなり、音も強く出ることがあります。

### Settings の大きさ

Settings パネルには3つの大きさがあります。

- `Small`: 画面を見ながらプリセットを回遊するための小さな表示です。
- `Medium`: 半分程度の高さで編集する表示です。
- `Large`: 細かく設定するための大きな表示です。

## 音

tamaping はブラウザの Web Audio を使います。多くのブラウザでは、音を
鳴らす前にユーザー操作が必要です。まず画面を一度タップまたはクリックして
ください。

音が鳴らない場合:

- 端末の音量を確認してください。
- ブラウザタブがミュートされていないか確認してください。
- アプリ画面内を一度タップまたはクリックしてください。
- ブラウザの音声許可や自動再生設定を確認してください。
- 古いスマートフォンでは、別のブラウザで挙動が変わることがあります。

音も実験の一部です。きれいに鳴るプリセットもあれば、衝突が重なって
ノイジーになったり、不安定で変な音になるプリセットもあります。

## ユーザープリセット

自分で調整した設定は、ユーザープリセット枠に保存できます。

ユーザープリセットはブラウザのローカルストレージに保存されます。

- 同じ端末、同じブラウザ内に保存されます。
- サイトデータを削除すると消えることがあります。
- サーバーにはアップロードされません。
- 端末間で自動共有されません。

## PCとスマートフォンでは印象が変わります

tamaping は画面の広さと物理の見え方が強く関係します。

PCで派手に見えるプリセットは、スマートフォンでは重く感じることがあります。
スマートフォン向けに気持ちよくしたプリセットは、PCでは少し落ち着いて
見えることがあります。

これは失敗というより、同じ仕組みを違う大きさの画面で触る面白さです。

## プライバシー

tamaping は静的なブラウザアプリです。

- アカウントは不要です。
- アナリティクスは入れていません。
- ユーザープリセットはブラウザ内にローカル保存されます。

## 推奨環境

新しめのPCブラウザ、スマートフォンブラウザを推奨します。

描画ライブラリ、物理シミュレーション、Web Audio を使うため、古い端末でも
開ける場合はありますが、密度の高いプリセット、パーティクル数の多い設定、
ブラウザの音声挙動で制限が出ることがあります。
